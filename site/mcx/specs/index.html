    三、防错备注¶

    警告： TS 24.280 和 TS 24.289 不存在——曾误传为 MCX 协议规范，经核对 3GPP 官方编号体系中并无这两条，本清单不收录。严禁在后续文档中误引。

    四、待核事项汇总¶

    1. TR 22.819 的公开版本号
    2. TR 23.790 的公开版本号
    3. B-TrunC联盟标准 具体编号
    4. 应急部2026年第6号公告 同批其余6项（非YJ/T 42系列）名单
    5. TS 24.281 / TS 24.282 / TS 24.483 已见 Rel-20 v20.0.0（2026-06），本基线暂按 Rel-19，后续跟踪升级

    Note

    版本号以 3GPP 官网公布为准，本清单定期跟踪更新；"待核"表示暂无公开可查的权威版本，持续核查中。
