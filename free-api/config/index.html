    免费 API 配置手册（codex / OpenAI 兼容工具通用）¶

    更新日期：2026-10-10

    导读：免费政策随时会变，动手前以官网为准。

    通用填法（三件套）¶

    任何 OpenAI 兼容工具（codex、Cherry Studio、NextChat、Cline 等）都只需填三样：

    参数 含义 示例
    base_url 供应商的 OpenAI 兼容端点 https://openrouter.ai/api/v1
    api_key 在供应商官网创建的 Key sk-apx…
    model 模型名（原样照抄） cohere/north-mini-code:free

    WorkBuddy（腾讯代码助手）等工具的自定义 API / 模型设置中，同样填入这三项：base_url、api_key、model（具体入口以其客户端设置为准）。

    推荐组合（写代码）¶

    • 首选：OpenRouter + cohere/north-mini-code:free（代码专用，免绑卡）
    • 备选：APInex + free/deepseek-v4-flash-0731
    • 故障转移链（额度实在程度排序）：NVIDIA NIM（40 RPM + 1 万/天，需免费 Key）→ Kilo 网关（200/小时/IP，免 Key）→ OVHcloud 匿名（2 RPM/IP/模型，仅作末位兜底）

    1. OpenRouter 免费模型池¶

    项 值
    官网 https://openrouter.ai
    base_url https://openrouter.ai/api/v1
    Key 获取 https://openrouter.ai/keys 自行创建

    免费模型（2026-10-09 用 or_models.py --free-only 实测在池，共 19 个；免费池会轮换，失效时换其他 :free 后缀模型）：

    模型名 上下文 特点
    cohere/north-mini-code:free 256K 代码专用小模型，写代码首选
    poolside/laguna-s-2.1:free 262K 代码模型
    poolside/laguna-xs-2.1:free 262K 轻量代码模型
    nvidia/nemotron-3-ultra-550b-a55b:free 1M 550B 大模型
    nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free 256K 推理模型
    inclusionai/ling-3.1-flash 262K 长文本
    google/gemma-4-31b-it:free 262K —
    • 免费限制：免费层约 20 RPM；免费模型更适合实验和低流量用途（以官网为准）
    • 备注：Muse 侧的 custom.openrouter 连接器 Key 由系统托管、不可见，不能直接拿来填，必须自己去官网创建一个。

    8. OVHcloud AI Endpoints（2026-10-10 据官方文档核实）¶

    项 值
    官网 https://www.ovhcloud.com/en/public-cloud/ai-endpoints/
    base_url https://oai.endpoints.kepler.ai.cloud.ovh.net/v1
    Key 获取 匿名通道免注册、免 Key、免绑卡；如需更高额度在 OVHcloud 控制台申请 API Key（按 token 计费，新 Public Cloud 账号有最多 200 美元试用额度）

    兼容：OpenAI 兼容（官网 Continue 教程直接用 openai provider 对接）。

    模型名 特点
    gpt-oss-120b 开源大模型
    Qwen3-Coder-30B-A3B-Instruct 代码专用
    • 免费限制：匿名每 IP 每模型 2 请求/分钟（官网原文），超限 429；持 Key 每项目每模型 400 RPM；社区实测匿名 2 RPM 为全球匿名调用者共享，可用性波动大，只适合做故障转移链末位
    • 注意：模型托管在欧盟数据中心，GDPR 合规

    10. Token Harbor（2026-10-10 据官方文档核实）¶

    项 值
    官网 https://tokenharbor.ai
    base_url https://tokenharbor.ai/v1（官方 Quickstart 原文；api.tokenharbor.ai 与 tokenharbor.ai/api/v1 实测 404）
    Key 获取 邮箱+密码或 Google 登录；免绑卡（官网原文 "no card is needed"）、免实名；Key 为 Universal Key，格式 thk_live_…，dashboard 只显示一次

    兼容：OpenAI 兼容（/chat/completions），Cherry Studio / Cursor / Continue 可直接对接。

    模型名 特点
    claude-haiku-5.5:free Haiku 5.5（Anthropic 10-07 新发布）限时免费，截止日期官方未公开
    deepseek-v4.1-flash:free 免费
    mimo-v2.6-flash:free 免费
    • 免费规则：模型 ID 以 :free 结尾的走免费路由，永不扣余额；免费路由默认关闭，需在 dashboard 手动 opt-in
    • 免费限制：额度按价值计算（value-based），未公布具体 RPM/RPD 数字；首次免费请求开启个人滚动 7 天周期，按 4 周分 4 个窗口发放，未用完不结转；:free 名单会轮换
    • 注意：① 限时免费模型可随时下线（条款 1.3 明确可随时移除、无需通知）；② 永久免费路由的 prompt/response 可能被保留用于诊断与模型改进，敏感代码走付费路由；③ 条款禁止用输出做蒸馏/训练；④ 官方用设备指纹+注册 IP 防多账号，勿用批量注册工具；法律实体 Token Harbor PTE. LTD.（新加坡）

    Codex 配置示例¶

    配置文件：~/.codex/config.toml（Windows：%USERPROFILE%\.codex\config.toml）

    # ~/.codex/config.toml
model = "cohere/north-mini-code:free"
model_provider = "openrouter"

[model_providers.openrouter]
name = "OpenRouter"
base_url = "https://openrouter.ai/api/v1"
env_key = "OPENROUTER_API_KEY"
wire_api = "chat"

[model_providers.apinex]
name = "APInex"
base_url = "https://api.apinex.bond/v1"
env_key = "APINEX_API_KEY"
wire_api = "chat"

[model_providers.zhipu]
name = "智谱 GLM"
base_url = "https://open.bigmodel.cn/api/paas/v4"
env_key = "ZHIPU_API_KEY"
wire_api = "chat"

[model_providers.nvidia_nim]
name = "NVIDIA NIM"
base_url = "https://integrate.api.nvidia.com/v1"
env_key = "NVIDIA_NIM_API_KEY"
wire_api = "chat"

[model_providers.kilo]
name = "Kilo Code Gateway"
base_url = "https://api.kilo.ai/api/gateway"
env_key = "KILO_API_KEY"
wire_api = "chat"

[model_providers.ovh]
name = "OVHcloud AI Endpoints"
base_url = "https://oai.endpoints.kepler.ai.cloud.ovh.net/v1"
env_key = "OVH_API_KEY"
wire_api = "chat"

[model_providers.tokenharbor]
name = "Token Harbor"
base_url = "https://tokenharbor.ai/v1"
env_key = "TOKENHARBOR_API_KEY"
wire_api = "chat"

    环境变量（Key 不写进文件）：

    export OPENROUTER_API_KEY="<在 https://openrouter.ai/keys 创建>"
export APINEX_API_KEY="sk-apx…"   # dashboard 创建
export ZHIPU_API_KEY="<在 https://bigmodel.cn/apikey/platform 创建>"
export NVIDIA_NIM_API_KEY="nvapi-…"   # build.nvidia.com 创建
export KILO_API_KEY="not-needed"      # 免费模型匿名调用，任意非空占位即可
export OVH_API_KEY="not-needed"       # 匿名通道同上
export TOKENHARBOR_API_KEY="thk_live_…"   # tokenharbor.ai 注册后创建（只显示一次）

    切换供应商：改顶层 model 与 model_provider 即可。

    注意事项¶

    • Key 不要硬编码：provider 块用 env_key = "环境变量名"，Key 通过 export 注入；环境变量名可自定义，env_key 与 export 名称保持一致。
    • 免费池会轮换：OpenRouter 免费池会轮换，失效时换其他 :free 后缀模型；各平台免费额度与限制以官网为准。
    • wire_api 版本差异：第三方 OpenAI 兼容端点一般设 wire_api = "chat"；新版 codex 默认 wire_api = "responses"，如遇报错请按所装版本文档调整。
    • 国内直连网络提示：Gemini 等境外服务国内直连可能需要网络条件；智谱、硅基流动为国内服务。
