# MCVideo和普通视频通话的区别？

很多新人觉得MCVideo（Mission Critical Video）不就是“高清版微信视频”吗？其实差别大了去了。普通视频通话追求的是“流畅”和“美观”，而MCVideo追求的是“实时”、“可控”和“证据留存”。

第一，时延控制。普通视频通话在弱网环境下可能会缓冲、卡顿，甚至花屏。而MCVideo针对关键任务场景优化，采用低时延编码策略，确保画面和声音几乎同步。对于警察看现场监控、医生远程指导手术，几百毫秒的延迟都可能造成严重后果，所以MCVideo对时延的容忍度极低。

第二，控制权限。普通视频是点对点的，你只能看你想看的人。但MCVideo支持“广播”和“监控”模式。比如指挥中心可以强制接入某个民警的摄像头画面，或者将某个现场画面分发给多个专家会诊。这种“非对称”的控制能力，是普通消费级视频通话完全不具备的。

第三，数据完整性。MCVideo通常要求视频流带有时间戳、地理位置、设备ID等元数据，并且支持本地录像和云端同步备份，确保证据链完整。普通视频通话往往只关注传输过程，很少考虑后续的取证需求。所以，MCVideo更像是一个“带传呼功能的执法记录仪”，而不是一个简单的聊天工具。
