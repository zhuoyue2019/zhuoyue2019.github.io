## MCX 是什么

MCX（Mission Critical Services，关键任务业务）是 3GPP 定义的一套基于公共蜂窝网络的关键任务通信服务集合。它旨在为公共安全及关键行业提供高可靠、低时延的宽带通信能力。MCX 包含三大核心业务：

*   **MCPTT**（Mission Critical Push To Talk，集群语音/一键通话）：支持类似对讲机的一键通话、组呼、紧急优先等功能。
*   **MCVideo**（集群视频）：支持实时视频流传输，包括单播和组播模式，用于现场态势感知。
*   **MCData**（集群数据）：支持关键任务数据的传输，如遥测数据、状态信息等。

这三大业务均构建在统一的公共架构 **TS 23.280** 之上，该架构定义了 MCX 服务的通用功能实体、接口及流程，确保了不同业务间的一致性和互操作性。

## 3GPP 为什么要做 MCX

传统关键任务通信主要依赖窄带技术（如 TETRA、LMR），其带宽有限，难以满足现代应急指挥对高清视频、大容量数据及多媒体融合的需求。3GPP 推动 MCX 开发的核心目标包括：

1.  **宽带化演进**：利用 LTE/5G 的高带宽特性，实现语音、视频、数据等多媒体集群通信，替代或补充窄带集群技术。
2.  **网络复用**：复用公共蜂窝网络（PLMN）的覆盖与容量，降低专网建设成本，提升网络资源利用率。
3.  **行业赋能**：为公安、消防、急救、铁路等行业提供标准化的宽带集群通信解决方案，提升应急响应效率与协作能力。

## 演进脉络

| 阶段 | 内容 |
| :--- | :--- |
| **Rel-13** | **MCPTT** 引入：首个 MCX 业务，奠定关键任务语音通信基础。 |
| **Rel-14** | **MCVideo / MCData** 补齐：扩展至视频与数据业务，形成多媒体集群能力。 |
| **Rel-17/19** | **MCX over 5GS**：基于 5G 系统（5GS）承载 MCX 业务，利用 5G 切片、低时延特性提升性能。 |
| **行业应用** | **FRMCS / 5G-R**：面向铁路的下一代移动通信系统，基于 5G 专网实现铁路关键任务通信。 |
