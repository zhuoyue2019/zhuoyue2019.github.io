# 3GPP MCX vs 中国方案对照

本页对照国际 3GPP MCX 体系与中国宽带集群/铁路5G方案，帮助读者理解“国际定框架、中国做场景化落地”。

### 维度对照表

| 维度 | 3GPP MCX（国际统一） | B-TrunC（中国） | 5G-R/FRMCS（铁路场景） |
| :--- | :--- | :--- | :--- |
| **标准体系** | 3GPP TS/TR 全系（22/23/24/33 系列，Stage 1/2/3 + 安全） | YD/T 2689-2014《基于LTE技术的宽带集群通信(B-TrunC)系统总体技术要求(第一阶段)》（通信行业标准，归口CCSA） | T/VSTR 031—2025《公网铁路应用总体技术要求》（团标，规范性引用TS 23.280/23.379/33.180）+ TJ/DW 239-2021、TJ/DW 246-2022（铁路行业暂行规范） |
| **技术体制** | SIP/IMS+5G 架构 | 中国TD-LTE宽带集群技术体制 | 基于3GPP MCX统一标准+5G，铁路场景化落地 |
| **业务能力** | MCPTT（关键一键通）、MCVideo（关键视频）、MCData（关键数据） | 宽带集群语音/数据/视频业务 | 铁路调度通信、列控数据等 |
| **承载网络** | LTE/5G（MCX over 5GS，TS 23.289 v19.7.0） | TD-LTE专网 | 5G-R：中国铁路5G专网；FRMCS：5G承载 |
| **典型应用** | 公共安全+FRMCS/5G-R | 国内宽带集群专网 | 铁路移动通信（FRMCS V3计划2027年底前推出） |
| **演进方向** | Rel-19冻结、部分规范已见Rel-20版本 | 向5G演进（联盟标准编号待核） | FRMCS基于MCX统一标准持续演进 |

### 关键结论

- **T/VSTR 031—2025 是“中国团标直接引用 3GPP MCX”的实证**：规范性引用 TS 23.280/23.379/33.180，证明中国铁路场景在 MCX 框架下做落地。
- **缺口**：公开渠道未见 CCSA 以“MCX/任务关键型”命名的明确标准号——中国尚未在通信行业标准层面直接对标命名 MCX。
- **频段对照**：中国 5G-R 试验频段 2100MHz（n1），欧洲 FRMCS 频段 1900-1910MHz（n101）；同一技术框架、不同频段政策。

**国际定框架、中国做场景化落地。**
