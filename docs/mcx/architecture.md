# 3GPP MCX 逻辑架构

本页基于 3GPP Release 19 规范，阐述任务关键型业务（Mission Critical Services，简称 MCX）的三层逻辑架构。对于应急通信从业者而言，理解此架构有助于厘清业务功能、公共支撑能力与底层承载之间的关系，确保设备选型与网络规划符合标准定义。

## 1. 业务层 (Service Layer)

业务层定义了终端用户可直接使用的核心通信能力，包括语音、视频和数据三类主要业务。

*   **MCPTT (Mission Critical Push-to-Talk)**：提供集群一键通话功能，支持通过 Floor Control（话权控制）机制实现单呼、群呼和广播，确保关键语音通信的优先级与秩序。
    *   Stage 2: [TS 23.379 v19.10.0](specs.md)
    *   Stage 3 信令: [TS 24.379 v19.6.0](specs.md)
    *   Stage 3 媒体面: [TS 24.380 v19.1.0](specs.md)
*   **MCVideo (Mission Critical Video)**：提供集群视频通信能力，支持实时视频共享与回传，适用于现场态势感知。
    *   Stage 2: [TS 23.281 v19.10.0](specs.md)
    *   Stage 3 信令: [TS 24.281 v19.6.0](specs.md)
    *   Stage 3 媒体面: [TS 24.581 v19.2.0](specs.md)
*   **MCData (Mission Critical Data)**：提供短数据交换、文件分发及基于终端的位置上报服务，满足非实时或半实时数据交互需求。
    *   Stage 2: [TS 23.282 v19.9.0](specs.md)
    *   Stage 3 信令: [TS 24.282 v19.7.0](specs.md)
    *   Stage 3 媒体面: [TS 24.582 v19.0.0](specs.md)

## 2. 公共使能层 (Common Enablers)

此层为上述业务提供统一的身份、群组、配置及安全支撑，避免各业务重复建设底层逻辑。

*   **公共架构**：定义 MCX 总体逻辑结构与通用流程 ([TS 23.280 v19.10.0](specs.md))。
*   **群组管理**：处理群组创建、成员变更及权限控制 ([TS 24.481 v19.1.0](specs.md))。
*   **身份管理**：负责用户身份验证、授权及目录服务 ([TS 24.482 v19.1.0](specs.md))。
*   **配置管理**：管理终端及网络侧的策略配置下发 ([TS 24.484 v19.4.0](specs.md))。
*   **管理对象**：定义网络管理接口的对象模型 ([TS 24.483 v19.2.0](specs.md))。
*   **安全**：规定 MCX 应用层的安全机制、密钥管理及隐私保护 ([TS 33.180 v19.3.0](specs.md))。

## 3. 承载层 (Bearer Layer)

承载层规定了 MCX 业务在移动通信网络中的传输机制，涵盖信令传输、媒体流传输及与异构网络的互通。

*   **SIP 核心信令**：基于 Session Initiation Protocol 实现会话建立与控制。
*   **媒体面**：传输语音、视频及数据媒体流。
*   **MCX over 5GS**：定义 MCX 在 5G 系统中的具体承载与路由机制 ([TS 23.289 v19.7.0](specs.md))。
*   **与 LMR 互通**：规定 MCX 与陆地移动无线电 (LMR) 系统间的互操作接口与协议适配 ([TS 23.283 v19.5.0](specs.md))。

## 需求侧参考

MCX 架构的设计响应了特定的行业需求规范，包括通用需求 [TS 22.280 v19.7.0](specs.md)、语音 [TS 22.179 v19.3.0](specs.md)、视频 [TS 22.281 v19.0.0](specs.md)、数据 [TS 22.282 v19.0.0](specs.md) 以及针对 5G-R 的场景需求 [TS 22.289 v19.0.1](specs.md)。各编号具体版本信息见 [标准清单](specs.md)。

> 注：TS 24.281、TS 24.282、TS 24.483 已见 Rel-20 v20.0.0，本页基线暂按 Rel-19。同时提醒：TS 24.280、TS 24.289 不存在，注意勿与 TS 23.280、TS 23.289 混淆。
